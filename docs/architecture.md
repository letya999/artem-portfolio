# Architecture

Astro produces static HTML at the domain root. Two React islands hydrate the portrait/career sculptures and the resource conveyor; Three.js renders their 3D scenes. The HTML contains profile content before hydration, so search engines and visitors without JavaScript can read it. The shared portrait renderer switches to a viewport-sized career scene while the experience section is visible. It no longer constructs an equation or transfers its letters into the first doll.

Canonical professional facts live in `src/portfolio-data.js` and `src/practice-data.js`. Interface translations live in `src/messages.json`. `scripts/generate-static.js` generates three Markdown resumes, three PDFs, the current six-outcome `llms.txt` index and agent profile snapshots during `npm run dev` and `npm run build`; edit source data rather than generated copies. `scripts/generate-resume-pdfs.js` prints the shared Markdown through a small scoped HTML formatter using Playwright. Embedded Noto Sans fonts cover Latin, Cyrillic and Kazakh; their license is in `scripts/assets/fonts/`. Local generation requires Chrome; CI installs Playwright Chromium. `python scripts/check-resume-pdfs.py` (pypdf 6.10.0) verifies the PDFs contain every Markdown text line and hyperlink, including correct Kazakh Unicode. `SITE_URL` supplies absolute canonical, hreflang, social, schema, sitemap, and robots URLs at build time.

The output is `dist/`; GitHub Actions builds and publishes that folder to GitHub Pages. `/ru`, `/en`, and `/kk` are the public language URLs (built from `.html` files), and `404.html` handles unknown paths. Static 3D JSON, GLB, images, fonts, and downloadable CV files are under `public/`. GitHub Pages controls response caching and compression; `public/_headers` applies only to the retained Cloudflare Pages fallback. REG.RU supplies production DNS; Cloudflare is outside the production DNS and HTTP paths once cached delegations expire. The first-screen portrait and logo images use WebP. Small self-hosted Noto Sans subsets fill the Kazakh glyphs missing from Manrope; other body text and Oswald headings keep the approved typography. The same static rendered portrait (`portrait-poster.webp`) covers initial HTML, module/data loading and WebGL failure. It is hidden only after the first real GPU frame, avoiding flashes of the colour photograph. Career progress eases toward scroll/toggle targets and snaps under reduced motion; it renders while transitioning and sleeps at rest. The AI view displays the exact localized `resumeMarkdown(t)` string in an escaped, wrapping, monospace `<pre>`, matching the downloadable Markdown; it does not build a separate HTML profile or hydrate the 3D islands.

The head contour asset and voxel JSON are sizeable; a fast edge response cannot remove browser parsing, GPU upload, and rendering cost. Keep WebGL failure and reduced-motion fallbacks. `ProfilePage`/`Person` JSON-LD identifies the current localized role, biography and PDF/Markdown documents. Canonicals and reciprocal language alternates use `SITE_URL`; sitemap dates come from `profileUpdated`. Node build-contract tests run separately via `npm run test:build`, before the production build. Playwright discovers only `*.spec.js`, so build tests cannot mutate generated assets during browser-test discovery. Browser tests under `tests/` cover presentation, localization, interactions, SEO, and agent resources; unit tests live beside source modules.
