# Product

The site presents Artem Letyushev's Tech / Delivery Project Manager experience to hiring managers, collaborators, and curious visitors. It explains outcomes, practice, work history, and ways to contact the owner.

Russian, English, and Kazakh pages use the same approved facts. Estimates, forecasts, prototypes, and work under NDA retain those labels. The owner-supplied CV and portraits are authoritative; do not fill gaps with invented metrics or synthetic likenesses.

The interface is a light editorial page with restrained motion. Text and contact links must remain usable without WebGL or JavaScript. Motion has a reduced-motion path. The original Russian PDF is linked from the Russian page; the English and Kazakh pages offer corresponding Markdown resumes.

The public site also exposes readable agent resources at `/skill.md`, `/agents.md`, `/llms.txt`, and `/mcp.json`. These are informational static files; the site does not run a remote MCP service.
